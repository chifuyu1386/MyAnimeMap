# 🎌 MyAnimeMap

### دنیای انیمه، در یک نگاه!

**MyAnimeMap** یک اپلیکیشن وب برای کشف، جست‌وجو و مشاهده اطلاعات انیمه‌های مختلف است. این پروژه با هدف ایجاد تجربه‌ای ساده، مدرن و لذت‌بخش برای علاقه‌مندان به انیمه توسعه داده شده است.

🌐 **نسخه آنلاین پروژه:**
https://chifuyu1386.github.io/MyAnimeMap/

---

## 📖 درباره پروژه

در MyAnimeMap می‌توانید انیمه‌های محبوب و پرطرفدار را کشف کنید، میان عناوین مختلف جست‌وجو کنید و اطلاعات جزئی‌تری درباره هر انیمه مشاهده کنید.

این پروژه با استفاده از React و TypeScript ساخته شده و تلاش شده است علاوه بر ساختار مناسب کد، رابط کاربری مدرن و واکنش‌گرا نیز داشته باشد.

### 🌍 چرا رابط کاربری پروژه انگلیسی است؟

با وجود اینکه این README به زبان فارسی نوشته شده، رابط کاربری MyAnimeMap به زبان انگلیسی طراحی شده است.

دلیل این تصمیم آن است که API مورد استفاده پروژه، اطلاعات انیمه‌ها را عمدتاً به زبان انگلیسی ارائه می‌دهد. به همین دلیل، برای حفظ یکپارچگی زبان رابط کاربری با محتوای دریافتی از API، زبان انگلیسی برای خود اپلیکیشن انتخاب شده است.

## ✨ قابلیت‌ها

- 🏠 **صفحه اصلی (Home):** مشاهده انیمه‌های پرطرفدار و ترند روز
- 🔎 **جست‌وجو و کاوش (Explore):** جست‌وجو و بررسی انیمه‌های مختلف
- 🎬 **جزئیات انیمه (Anime Details):** مشاهده اطلاعات هر انیمه در صفحه‌ای اختصاصی
- ⭐ **نمایش امتیاز:** مشاهده امتیاز انیمه‌ها در صورت وجود اطلاعات
- 📺 **اطلاعات قسمت‌ها:** مشاهده تعداد قسمت‌ها و وضعیت انتشار
- 📝 **خلاصه داستان:** مطالعه توضیحات و خلاصه داستان انیمه‌ها
- 📱 **طراحی واکنش‌گرا (Responsive):** سازگار با اندازه‌های مختلف صفحه‌نمایش
- ⏳ **مدیریت وضعیت بارگذاری:** نمایش وضعیت دریافت اطلاعات
- ⚠️ **مدیریت خطا:** نمایش پیام مناسب هنگام بروز مشکل در دریافت اطلاعات
- 🧭 **مسیریابی صفحات:** جابه‌جایی میان بخش‌های مختلف برنامه

## 🛠️ تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|---|---|
| React | ساخت رابط کاربری مبتنی بر کامپوننت |
| TypeScript | افزایش اطمینان از صحت کد با استفاده از سیستم نوع‌دهی |
| Vite | ابزار توسعه و Build پروژه |
| Tailwind CSS | طراحی و استایل‌دهی رابط کاربری |
| React Router | مدیریت مسیرها و جابه‌جایی میان صفحات |
| Kitsu API | دریافت اطلاعات انیمه‌ها |
| Git & GitHub | مدیریت نسخه‌ها و نگهداری کد پروژه |
| GitHub Actions | خودکارسازی Build و انتشار پروژه |
| GitHub Pages | میزبانی نسخه آنلاین پروژه |
